# Data

This directory is intentionally empty. The DementiaBank Pitt Corpus cannot be redistributed.

To obtain the data, apply for DementiaBank membership: https://dementia.talkbank.org/

Your CSV should have the following columns:

| Column | Description |
|--------|-------------|
| `utts` | Participant-only transcript text (interviewer speech removed) |
| `labels` | `0` = Dementia, `1` = Healthy |

Place your CSV in this directory and update the filename in the notebook.
